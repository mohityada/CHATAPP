CHATAPP is a real-time chat application that allows users to connect, communicate, and collaborate. It features an intuitive user interface and leverages modern web technologies for seamless messaging.

## Introduction

CHATAPP is designed to provide a reliable and user-friendly platform for real-time messaging. It can be used for personal, professional, or educational purposes, enabling users to stay connected wherever they are.

---

## Features

- Real-time messaging with instant delivery.
- User authentication for secure access.
- Chat rooms for group conversations.
- One-on-one private messaging.
- Online/offline user status indicators.
- Responsive design for web and mobile devices.

---

## Technologies Used

- **Frontend**: HTML, CSS, JavaScript, React (optional)
- **Backend**: Node.js, Express.js
- **Database**: MongoDB
- **Real-time Communication**: Socket.IO

## Installation

Follow these steps to set up the project locally:

1. Clone the repository:
   ```bash
   git clone https://github.com/mohityada/CHATAPP
   ```

2. Navigate to the project directory:
   ```bash
   cd CHATAPP
   ```

3. Install dependencies:
   ```bash
   npm install
   ```

4. Set up environment variables:
   - Create a `.env` file in the root directory.
   - Add the following variables:
     ```env
     PORT=5000
     MONGO_URI=YourMongoDBConnectionString
     JWT_SECRET=YourSecretKey
     ```

5. Start the application:
   ```bash
   npm start
   ```

6. Open your browser and navigate to:
   ```
   http://localhost:5000
   ```

## Usage

1. **Sign Up**: Create a new account by providing your details.
